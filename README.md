# レーンシューター・ラッシュ

YouTube広告でよく見るタイプの、3レーン式ラン＆シューティングのミニゲームです。

## 遊び方

- 3つのレーンから進む道を選びながら、自動で撃ち続けて前進します
- 🟢 **仲間レーン**：プレイヤーの人数が増える
- 🔵 **武器レーン**：武器が強くなる（ダメージ＆連射アップ）
- 🔴 **敵レーン**：HP付きの敵の大群が出現
- 数字HPの敵ブロックを撃ち破れ。敵が到達すると、残りHPに応じて仲間が減ります
- 仲間が0人になったらゲームオーバー

## 操作

- ← → キー / A・D キー
- スワイプ、画面タップ（左右）
- 画面下の ◀ ▶ ボタン

## 技術

HTML + Canvas + JavaScript の単一ファイル（`index.html`）だけで動きます。GitHub Pagesでそのまま公開できます。
