# レーンシューター・ラッシュ

YouTube広告でよく見るタイプの、3レーン式ラン＆シューティングのミニゲームです。

## 遊び方

- 3つのレーンから進む道を選びながら、自動で撃ち続けて前進します
- 🔴 **敵は真ん中のレーン**に止めどなく流れ続けます
- ゲートは固定配置：⬅️ **左＝🟢仲間レーン**（人数が増える）、**真ん中＝🔴敵の大群**、➡️ **右＝🔵武器レーン**（ダメージ＆連射アップ）
- 数字HPの敵ブロックを撃ち破れ。同じレーンの敵が到達すると、残りHPに応じて仲間が減ります
- 仲間が0人になったらゲームオーバー

## 操作

- ← → キー / A・D キー
- スワイプ、画面タップ（左右）
- 画面下の ◀ ▶ ボタン

## 技術

HTML + Canvas + JavaScript の単一ファイル（`index.html`）だけで動きます。GitHub Pagesでそのまま公開できます。
